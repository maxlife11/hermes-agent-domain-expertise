- **Score 5.0** · 4★ · pushed 2026-11-20 · Python · MIT · PyPI `headron-software`
- **What it is:** a rule contract plus CLI that maps changed files to checks. `headron port <file>` tells an agent what a file owes *before* it edits; `atlas.yaml` holds the checks; `headron verify` emits PASS / FAIL / SKIP / NOT RUN and `--receipt <file>` produces a signed verdict. `headron init` writes AGENTS.md, CLAUDE.md, `.mcp.json`, `.codex/config.toml`, `.cursor/mcp.json` and a pre-commit hook.
- **Why it beat the rest:** it is the only verification tool this run that treats *unrun* as a distinct third state. Every other "agent QA" repo collapses "didn't check" into "passed", which is exactly the failure mode that produced the stuck probe issue on the KB repo.
