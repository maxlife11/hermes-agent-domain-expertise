## 1. What this run found

**1. The MCP Registry is a better discovery channel than star-ranked search for this user's niche.** Querying `registry.modelcontextprotocol.io` returned 1,200 servers, 129 of which map to GitHub repos and 28 of which are business-relevant (real estate, local business, lead gen, ads, CRM, SEO). Sixteen of today's 30 selected repos came from that channel at **0–1 stars** — `datadubai`, `MCP-Dubai`, `getlead-mcp`, `apogee-mcp`, `adako-mcp`, `a1lane-mcp`, `web-content-mcp-server`, `askyouraudience`, `api-blitz/skills` — and not one of them would have survived a stars-sorted search. Precision stayed at 1.00 while the median star count of selected repos fell from ~11,000 (run 0001) to ~500. In this domain, relevance is now a *distribution* signal (published to the registry, packaged for MCP clients), not a popularity signal.

**2. Self-improvement has become a commodity loop with a specific shape.** Four independent implementations shipped this month and they agree on the design: *propose → score → keep or roll back*, with a holdout and a blocking gate. `alchaincyf/darwin-skill` v3.0 replaced "judges read the docs" with **blind scoring of actual run outputs**; `Protocol-zero-0/evolution-kernel` scores changes against a **null-model control** and uses git commits as the rollback unit; `jjanczur/tyran` moves quality rules from prompts into **hooks that block**; `Tencent/LoopForge` adds **human approval gates and a shared audit trail**. The user's `self-improving-agent` repo describes the same governance idea ("Board of Directors") in prose — the code now exists off the shelf.

**3. The portfolio is 15 forks and 4 originals, and the forks are drifting.** Eleven of the 15 `maxlife11` repos are forks with zero local commits; two of them (`last30days-skill`, `marketingskills`) are forks of repos that are trending or leading their category *today*. Meanwhile the one original commercial asset — `Support-Local-Businesses.com`, with 6.4M listings, a free API and an agent card — has **no MCP server**, while 0-star directories in the registry (`datadubai`, `1325ai`) publish one and get found by agents. The highest-leverage move available is not more scanning: it is wrapping SLB's API as an MCP server and publishing it to the registry.
